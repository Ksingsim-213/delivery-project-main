Phase 1: ตั้งไข่โปรเจกต์ (Setup & Infrastructure)
เป้าหมายคือสร้างโปรเจกต์ โครงสร้างไฟล์ และเชื่อมต่อฐานข้อมูลให้พร้อมทำงาน

[X] สร้างโปรเจกต์และตั้งค่า TypeScript

ไฟล์อ้างอิง: 01-Web API.md

สิ่งที่ต้องทำ: เปิด Terminal สร้างโฟลเดอร์ รัน npm init --yes จากนั้นติดตั้ง TypeScript, Express, ts-node-dev และ @types/express ตามคำสั่งในไฟล์ สร้าง tsconfig.json, app.ts, และ server.ts เพื่อรันเซิร์ฟเวอร์ให้ติด

[X] ติดตั้งตัวแปลภาษาและเปิดรับรีเควสแบบ JSON

ไฟล์อ้างอิง: 04-Request Handler.md

สิ่งที่ต้องทำ: ไปที่ไฟล์ app.ts เพิ่มคำสั่ง app.use(express.json()); และ app.use(express.text()); เพื่อให้ระบบเราอ่านข้อมูลที่ Angular ส่งมาได้

[x] เชื่อมต่อฐานข้อมูล MySQL (หัวใจสำคัญ)

ไฟล์อ้างอิง: 06-Database Connection.md

สิ่งที่ต้องทำ: ติดตั้งแพ็กเกจ mysql2 สร้างไฟล์ dbconnect.ts และเขียนโค้ดเพื่อทำ Connection Pool (เปลี่ยนข้อมูล user, password, database ให้ตรงกับของคุณ)

[X] จัดระเบียบเส้นทาง (Routing & Controller)

ไฟล์อ้างอิง: 02-Controller.md

สิ่งที่ต้องทำ: สร้างโฟลเดอร์ controller เพื่อแยกการจัดการ API เช่น customer.ts (จัดการลูกค้า), order.ts (จัดการออเดอร์) และ route.ts (จัดการการคำนวณเส้นทาง) จากนั้นไปเชื่อมต่อใน app.ts

[X] เปิดประตูให้ฝั่ง Front-end (Angular) เข้าถึงได้

ไฟล์อ้างอิง: 12-CORS.md

สิ่งที่ต้องทำ: ติดตั้งแพ็กเกจ cors และเพิ่มคำสั่ง app.use(cors({ origin: "*" })); (หรือระบุโดเมนของ Angular) ลงใน app.ts ไว้ด้านบนสุด เพื่อป้องกันปัญหาการบล็อกข้ามโดเมน

Phase 2: ออกแบบและจัดการข้อมูล (Data & CRUD)
เป้าหมายคือสร้างโมเดลข้อมูลให้ชัดเจน และทำระบบ เพิ่ม ลบ แก้ไข (CRUD) พื้นฐานให้ร้านข้าวกล่อง

[X] ออกแบบโมเดลข้อมูล (Interface)

ไฟล์อ้างอิง: 07.01-Model Serialization.md

สิ่งที่ต้องทำ: สร้างโฟลเดอร์ model และกำหนดโครงสร้างข้อมูลให้ชัดเจน เช่น Customer, Order, RiderJob (ใช้เครื่องมืออย่าง QuickType.io ช่วยแปลจาก JSON เป็น TypeScript ตามที่ไฟล์แนะนำ)

[X] สร้าง API ดึงข้อมูลและค้นหา (GET)

ไฟล์อ้างอิง: 07-Query.md, 04-Request Handler.md, 05-Response Handler.md

สิ่งที่ต้องทำ: ใน controller (เช่น customer.ts, order.ts) เขียน API ดึงข้อมูลโดยใช้ req.params (เช่นหาด้วย ID) หรือ req.query (ค้นหาแบบมีเงื่อนไข) และใช้ res.json() ส่งข้อมูลกลับ (อย่าลืมใช้ ? ใน SQL ป้องกัน SQL Injection)

[X] สร้าง API บันทึกข้อมูล (POST - Insert)

ไฟล์อ้างอิง: 08-Insert.md

สิ่งที่ต้องทำ: เขียน API สำหรับรับออเดอร์ใหม่ หรือเพิ่มลูกค้าใหม่ โดยรับข้อมูลจาก req.body แปลงให้เข้ากับ Interface แล้วสั่ง INSERT ลงฐานข้อมูล

[X] สร้าง API อัปเดตข้อมูล (PUT - Update)

ไฟล์อ้างอิง: 10-Update.md

สิ่งที่ต้องทำ: เขียน API สำหรับแก้ไขข้อมูล (เช่น ร้านค้ากดแก้ไขจำนวนข้าวกล่อง) แนะนำให้ใช้แบบ "Dynamic Merge" (ดึงข้อมูลเก่ามาผสมของใหม่) เพื่อความยืดหยุ่น

[X] สร้าง API ลบข้อมูล (DELETE)

ไฟล์อ้างอิง: 09-Delete.md

สิ่งที่ต้องทำ: เขียน API สำหรับลบออเดอร์ (กรณีลูกค้าแคนเซิล) โดยรับ ID ผ่าน req.params

Phase 3: ฟีเจอร์พิเศษและทดสอบระบบ (Advanced & Testing)
เป้าหมายคือทำระบบคำนวณเส้นทาง (ตามโจทย์ Project.pdf), ฟีเจอร์ยืนยันตัวตน, อัปโหลด และเตรียมขึ้นระบบจริง

[ ] สมองกลจัดเส้นทาง (The Brain - จุดสำคัญของโจทย์!)

ไฟล์อ้างอิง: (ต้องประยุกต์ความรู้จากหลายไฟล์)

สิ่งที่ต้องทำ: สร้าง API (เช่น POST /api/route/calculate) ใน route.ts ที่รับข้อมูลออเดอร์ทั้งหมดมา แล้วเขียนลอจิกคณิตศาสตร์เพื่อ:

จับกลุ่มออเดอร์ให้ไรเดอร์ (ไม่เกิน 3 กล่อง/คน)

หาเส้นทางที่สั้นที่สุด (อาจใช้พิกัด latitude/longitude ที่ได้จากโจทย์)

คำนวณต้นทุน (15 + (2 x ระยะทาง x จำนวนกล่อง))

ตอบกลับเป็น JSON ที่สรุปเส้นทางและต้นทุน เพื่อให้ Admin และ Rider ไปแสดงผล

[ ] ทดสอบ API ก่อนไปต่อ Angular

ไฟล์อ้างอิง: 03-API Tester.md

สิ่งที่ต้องทำ: ใช้โปรแกรมอย่าง Postman, Bruno, หรือ Talend API Tester ยิงทดสอบ API ทุกเส้น (GET, POST, PUT, DELETE) ตรวจดูว่าทำงานได้ถูกต้อง ตอบกลับ JSON สวยงามและแสดง Error ถูกต้องตามสถานะ (เช่น 200, 201, 404, 500)

[ ] ระบบอัปโหลดรูปภาพ (ถ้ามี)

ไฟล์อ้างอิง: 11-Upload File.md

สิ่งที่ต้องทำ: ถ้าโจทย์มีการให้ร้านค้าอัปโหลดรูปเมนูอาหารหรือสลิปโอนเงิน ให้ติดตั้ง multer และ uuid เพื่อจัดการการอัปโหลดไฟล์ และกำหนดโฟลเดอร์สำหรับเก็บไฟล์

[ ] ระบบยืนยันตัวตนด้วย JWT (ถ้ามี)

ไฟล์อ้างอิง: 13-JWT (Optional).md

สิ่งที่ต้องทำ: หากระบบต้องมีการแยกสิทธิ์ระหว่าง Admin (ร้านค้า) กับ Rider คุณต้องติดตั้ง jsonwebtoken และสร้าง Middleware ไว้ใน app.ts เพื่อเช็คว่าใครมีสิทธิ์เข้าถึง API ไหนบ้าง (ต้องแนบ Token ใน Header ด้วยคำว่า Bearer)

ไฟล์อ้างอิง: 14-Deployment.md

สิ่งที่ต้องทำ: เมื่อทดสอบผ่านหมด ให้แปลงโค้ด TypeScript เป็น JavaScript ด้วยคำสั่ง npx tsc จากนั้นจะเลือกดีพลอยผ่านบริการอย่าง Render.com (อัปโหลดผ่าน GitHub) หรือทำเป็น Docker Container ก็ได้ตามความถนัด
